# Asset sources

- Portrait: user-selected Photo 3, background extracted with image_gen and imported into Figma. Exact preparation prompt is in the portrait PNG JSON sidecar. Binary text map preserves the Figma six-layer character artwork.
- LagosNet: genuine published project screenshot. Origin is in its PNG JSON sidecar.
- Navigation icons: Lucide official icon sources, imported as native vectors into the approved Figma design; ISC license included.
- Manrope and IBM Plex Mono: Google Fonts, locally hosted; official OFL licenses included.
- Dotted field, pointer illumination, portrait alpha mask and reveal boundary: exports of the approved native Figma layers.
